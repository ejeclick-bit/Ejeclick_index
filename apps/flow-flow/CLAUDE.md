# Flow Flow — Proyecto Barbería

Orquestador interno para el ecosistema Flow Flow.

## Proyectos

| Proyecto | Descripción | Puerto |
|---|---|---|
| `landing` | Landing page pública para clientes | :3002 |
| `admin` | Panel administrativo (frontend + backend) | :3003 / :8001 |

## Dock

```bash
npm run dev:landing         # Landing :3002
npm run dev:admin           # Admin frontend :3003
npm run dev:admin:backend   # Admin backend :8001
```
